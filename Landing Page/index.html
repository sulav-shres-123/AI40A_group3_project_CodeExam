🔒

Summative Examination Deck

High-stakes invigilation pipeline
Locked & Authoritative

Engineered for formal examination halls where final grades carry absolute legal and ABET scrutiny. Untrusted student code is safely isolated under massive burst concurrency.

  • Server-Authoritative Clock: Browser JavaScript timer controls countdown logic, but server dates override and cannot circumvent server-enforced submission deadlines.
  • Judge0 Isolated Sandbox: Hardened Linux cgroups enforce rigid CPU time bounds, wall-clock limits, network air-gaps, and fork-bomb prevention.
  • Hidden Test Matrix & Partial Credit: Students validate public test samples locally; formal submission triggers unexposed test vectors calculating deterministic scores.
  • Integrity Event Ledger: Tab switches, window blurs, and paste events are logged with UTC timestamps and streamed directly to proctor dashboards.
  • Faculty Override Audit Trail: Professors preserve final authority to reward partial marks with written justifications stored in an immutable audit table.

Formative Learning Hub

Continuous Mastery

Engineering Philosophy

Runtime containers run with zero outbound network routing. Untrusted code cannot fetch answers from external web APIs or attack university intranet gateways.
